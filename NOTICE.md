# Provenance and content policy

This repository contains the original prompt-profile editor, compiler and storage adapter. It interoperates with [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) and the observable JSON format of [SillyTavern](https://github.com/SillyTavern/SillyTavern).

It is not affiliated with either upstream team. No upstream application source, story pack, character card, third-party prose/prompt collection, logos or artwork are bundled. React and DSH UI primitives are provided by the host. The MIT license covers this implementation, not content a user imports.

Tests contain synthetic structural values to verify behavior; none are seeded into production. Users are responsible for permission to import or redistribute their own material.
